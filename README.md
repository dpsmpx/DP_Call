# DP Call

**Минималистичная голосовая звонилка: P2P, без серверов, регистрации и номера телефона.**

В обычной сборке разговор идёт напрямую между двумя телефонами (WebRTC, DTLS-SRTP). Вызов доставляется
зашифрованным через публичные релеи Nostr — собственных серверов у приложения нет.

## Установка

- **Скачать APK:** [DP_Call.apk][apk] — всегда последняя версия (Android 8.0+, около 23 МБ)
- **С Tor:** [DP_Call-Tor.apk][apk-tor] — то же приложение со встроенным Tor и мостами для
  сигнального канала (около 38 МБ), см. [сборку с Tor](docs/USER_GUIDE.md#сборка-с-tor)
- **Все выпуски:** [GitHub Releases][releases]

Обе сборки — одно приложение: одну можно поставить поверх другой, код и контакты сохранятся.

<img src="docs/images/download-qr.png" width="180" alt="QR-код: скачать DP Call">

Наведите камеру телефона на QR-код — откроется скачивание последней версии.
- [Руководство пользователя](docs/USER_GUIDE.md)

Приложение само сообщает о новой версии: раз в сутки спрашивает у GitHub номер последнего
выпуска и показывает кнопку «Скачать». Проверку можно отключить в настройках.

## Возможности

- Вызов доходит до собеседника сам: у него звонит телефон, даже если приложение закрыто
- Входящий звонок — стандартное уведомление «Принять / Отклонить», в том числе поверх экрана блокировки
- Звонок продолжается в свёрнутом приложении; в шторке — «Завершить» и «Микрофон»
- Ответ и завершение кнопкой проводной или Bluetooth-гарнитуры (системный Telecom)
- Выключение микрофона, выбор вывода звука: телефон / динамик / гарнитура / Bluetooth
- Шумоподавление в обе стороны, эхоподавление, автоусиление, Opus 48 кГц с коррекцией потерь
- Индикатор качества связи и строка «насколько хорошо слышно собеседника», таймер,
  мгновенное завершение у обоих собеседников
- Битрейт Opus подстраивается под канал: при потерях снижается, на чистой связи возвращается
- Звонок переживает смену сети (Wi-Fi ↔ мобильная): соединение пересогласуется на лету
- Кнопка «Пригласить»: QR-код и прямая ссылка на скачивание приложения для тех, у кого его ещё нет
- Обмен кодами по QR: отсканированный код сразу предлагает «Позвонить» или «Сохранить»;
  код находится в сообщении в любом виде — разбитый на части, в кавычках, с опечатками O/0
- Журнал звонков; «Поделиться → DP Call» с кодом открывает ту же карточку
- Пропущенный звонок виден, даже если телефон был не в сети: зашифрованная отметка ждёт на релеях 48 часов
- Плашка готовности: зелёная, только когда звонок действительно дойдёт, иначе подсказывает, что исправить;
  нажатие открывает проверку связи — релеи, прямой путь, TURN
- Надёжная доставка вызова: релеи, которые подводят, временно отстраняются, их место
  занимают запасные; приглашение повторяется чаще в первые секунды
- Работа в российских сетях: STUN Яндекса, соединения с релеями обновляются до того, как
  замрут на ~16 КБ, плашка распознаёт режим белых списков мобильного интернета; подробный
  тест сети с отчётом; «Сообщить по SMS», если вызов не доходит
- Подсказки для Xiaomi, Huawei, Honor, OPPO, realme, OnePlus, vivo, Samsung и др.: что
  разрешить в оболочке, с переходом в нужный экран; режим «Постоянная связь» для телефонов,
  которые всё равно закрывают приложение
- Резервная копия кода и контактов в файл под паролем — для переноса на другой телефон
- Сообщение о новой версии со ссылкой на GitHub Releases
- Звонок от незнакомого кода можно принять и сразу сохранить в контакты
- Свой TURN-сервер и список релеев в настройках
- Интерфейс на русском и английском
- Вводная инструкция при первом запуске

## Как позвонить

1. Обменяйтесь кодами (текстом или QR) и добавьте собеседника в контакты.
2. Нажмите «Позвонить» — у собеседника зазвонит телефон.
3. Он нажимает «Принять» — разговор начинается.

Если собеседник не на связи, приглашение можно отправить вручную через любой мессенджер.
Подробнее — в [руководстве](docs/USER_GUIDE.md).

## Приватность

- Нет учётных записей, номеров, адресной книги, аналитики и рекламы.
- Код пользователя — публичный ключ; секретный ключ хранится только на устройстве
  под защитой Android Keystore.
- Релей видит IP-адрес (при VPN — адрес VPN), обезличенный тег получателя и время.
  Кто звонит, коды собеседников и параметры соединения зашифрованы.
- Сигналы вызова релеи не хранят. Исключение — отметка о пропущенном звонке: она
  зашифрована так же, хранится 48 часов и отключается в настройках.
- Раз в сутки приложение запрашивает у GitHub номер последней версии (отключается).
- В сборке с Tor релеи и GitHub видят адрес выхода Tor, а не ваш IP. Голос и проверка
  связи идут мимо Tor: собеседник, STUN- и TURN-серверы видят ваш адрес, как и в обычной сборке.
- Для установления прямого соединения используются публичные STUN-серверы; если прямой
  путь невозможен, нужен TURN-ретранслятор — встроенный публичный работает не всегда,
  надёжнее указать свой (см. [руководство](docs/USER_GUIDE.md#свой-turn-сервер-когда-нужен-и-где-взять)).

Подробности: [политика конфиденциальности](docs/PRIVACY.md), [ADR-002](docs/adr/002-relay-signaling.md).

## Принципы

- Только голос (без видео, чатов, файлов)
- Только Android (8.0+)
- Полностью открытый исходный код (MIT)
- Никаких собственных серверов разработчика
- Дистрибуция: GitHub Releases

## Сборка

```bash
./gradlew assembleStandardDebug    # отладочная, без Tor
./gradlew assembleTorDebug         # отладочная, с Tor
./gradlew assembleRelease          # обе релизные
./gradlew testStandardDebugUnitTest testTorDebugUnitTest   # модульные тесты
```

Требуется JDK 17 и Android SDK 35; minSdk 26.

Каждый push в `main` собирается в GitHub Actions и публикуется в [Releases](../../releases).
Как выпускать версии и подключить собственный ключ подписи — в [docs/RELEASING.md](docs/RELEASING.md).
