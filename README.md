# DP_Call

**Минималистичная голосовая звонилка с pure P2P (WebRTC)**

Без собственных серверов. Без регистрации. Без номера телефона.
Контакты добавляются по уникальному коду (это публичный ключ). Вызов доставляется
зашифрованным через публичные релеи Nostr; сам разговор идёт напрямую между устройствами.

## Принципы

- Только голос (без видео, без чатов)
- Только Android
- Полностью открытый исходный код (MIT)
- Дистрибуция: GitHub Releases + F-Droid
- Пользователи предполагаются со стабильным VPN
- TURN — опционально, только публичные бесплатные серверы
- Сигналинг — публичные релеи Nostr, без регистрации и учётных записей

## Статус

В активной разработке. Работает как обычная звонилка:

- входящий звонок — стандартное всплывающее уведомление «Принять / Отклонить» (и поверх экрана блокировки);
- звонок продолжается в свёрнутом приложении; в шторке — уведомление с кнопками «Завершить» и «Микрофон»;
- ответ и завершение кнопкой проводной или Bluetooth-гарнитуры (системный Telecom);
- выключение микрофона, выбор вывода звука: телефон / динамик / гарнитура / Bluetooth;
- шумоподавление в обе стороны, эхоподавление, автоусиление, Opus 48 кГц с коррекцией потерь;
- индикатор качества связи, таймер, мгновенное завершение у обоих собеседников.

## Как позвонить

1. Обменяйтесь кодами и добавьте друг друга в контакты (оба должны добавить друг друга).
2. Нажмите «Позвонить» — у собеседника зазвонит телефон, даже если приложение закрыто.
3. Он нажимает «Принять» — разговор начинается.

Чтобы звонки доходили в фоне, приложение держит соединение с релеями (тихое уведомление
«Ожидание звонков»). В настройках стоит разрешить работу без ограничений батареи.

Если собеседник не на связи, приглашение можно отправить вручную через любой мессенджер
(«Отправить приглашение вручную»), как раньше.

### Приватность

Релей видит только IP-адрес, обезличенный тег получателя и время. Кто звонит, коды
собеседников и параметры соединения зашифрованы. Подробности: [ADR-002](docs/adr/002-relay-signaling.md).

## Сборка

```bash
./gradlew assembleDebug
```

Требуется Android SDK 35, minSdk 26.

Каждый push в `main` собирается в GitHub Actions и публикуется в
[Releases](../../releases) как отладочный APK (подписан общим тестовым ключом из репозитория).
Чтобы там же появлялась подписанная релизная сборка, добавьте секреты репозитория
`DPCALL_KEYSTORE_BASE64`, `DPCALL_KEYSTORE_PASSWORD`, `DPCALL_KEY_ALIAS`, `DPCALL_KEY_PASSWORD`.
