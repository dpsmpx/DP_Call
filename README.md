# DP_Call

**Минималистичная голосовая звонилка с pure P2P (WebRTC)**

Без серверов. Без регистрации. Без номера телефона.
Контакты добавляются по уникальному коду. Обмен SDP — вручную через буфер обмена.

## Принципы

- Только голос (без видео, без чатов)
- Только Android
- Полностью открытый исходный код (MIT)
- Дистрибуция: GitHub Releases + F-Droid
- Пользователи предполагаются со стабильным VPN
- TURN — опционально, только публичные бесплатные серверы

## Статус

В активной разработке. Работает как обычная звонилка:

- входящий звонок — стандартное всплывающее уведомление «Принять / Отклонить» (и поверх экрана блокировки);
- звонок продолжается в свёрнутом приложении; в шторке — уведомление с кнопками «Завершить» и «Микрофон»;
- ответ и завершение кнопкой проводной или Bluetooth-гарнитуры (системный Telecom);
- выключение микрофона, выбор вывода звука: телефон / динамик / гарнитура / Bluetooth;
- шумоподавление в обе стороны, эхоподавление, автоусиление, Opus 48 кГц с коррекцией потерь;
- индикатор качества связи, таймер, мгновенное завершение у обоих собеседников.

## Как позвонить

1. Обменяйтесь кодами и добавьте друг друга в контакты.
2. A нажимает «Позвонить» и отправляет приглашение в любой мессенджер («Отправить»).
3. B в мессенджере: «Поделиться → DP Call» (или копирует приглашение и открывает приложение) —
   появляется входящий звонок. B нажимает «Принять» и отправляет ответ обратно.
4. A копирует ответ и возвращается в DP Call (или «Поделиться → DP Call») — разговор начинается.

Серверов нет, поэтому приглашение доставляет сам пользователь: «позвонить» в закрытое приложение
без такого обмена нельзя.
