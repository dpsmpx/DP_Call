# Design

Минималистичный Material 3 интерфейс.

- Одна главная функция: звонки
- Светлая / тёмная тема (system + dynamic color)
- Крупный моноширинный код identity
- Экран звонка: аватар с пульсацией, таймер, индикатор качества связи
- Обмен кодами — пошаговые карточки с «Отправить» / «Копировать»
- Управление: микрофон, шумоподавление, вывод звука, завершить
- Входящий: «Принять» / «Отклонить» на экране и в уведомлении
- Главный экран: индикатор связи, свой код, контакты; настройки — в диалоге
- Первый запуск: вводная инструкция из четырёх шагов, затем запрос разрешений
- Ручной обмен кодами спрятан за кнопкой, пока вызов доставляется автоматически
