# Техническое задание — DP_Call

**Версия:** 0.3  
**Статус:** Утверждено

## Цель

Минималистичное Android-приложение для голосовых P2P-звонков без серверов и регистрации.

## Ключевые решения

| Тема | Решение |
|------|----------|
| Платформа | Только Android |
| Медиа | Только голос |
| Идентичность | Локальный код (Crockford Base32, 26 символов) |
| Контакты | По коду, локальное хранение |
| Сигналинг | Ручной обмен SDP через буфер обмена |
| Формат | `DPCALL1.<O\|A>.<base64url(gzip(json))>` |
| TURN | Опционально, только публичные бесплатные (openrelay) |
| Дистрибуция | GitHub Releases + F-Droid |
| Лицензия | MIT |

## Сценарий звонка

1. A: создать Offer → скопировать → отправить B
2. B: вставить Offer → создать Answer → скопировать → отправить A
3. A: вставить Answer → ICE → CONNECTED

## Не входит в scope

- Видео, чаты, файлы
- Собственные серверы разработчика
- Регистрация / номер телефона
