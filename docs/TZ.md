# Техническое задание — DP_Call

**Версия:** 0.3  
**Статус:** Утверждено

## Цель

Минималистичное Android-приложение для голосовых P2P-звонков без серверов и регистрации.

## Ключевые решения

| Тема | Решение |
|------|----------|
| Платформа | Только Android |
| Медиа | Только голос |
| Идентичность | Пара ключей secp256k1; код — публичный ключ (Crockford Base32, 52 символа) |
| Контакты | По коду, локальное хранение |
| Сигналинг | Публичные релеи Nostr, E2E-шифрование (ADR-002); ручной обмен SDP — запасной путь |
| Формат | `DPCALL1.<O\|A>.<base64url(gzip(json))>` |
| TURN | Опционально, только публичные бесплатные (openrelay) |
| Дистрибуция | GitHub Releases + F-Droid |
| Лицензия | MIT |

## Сценарий звонка

1. A: «Позвонить» → Offer уходит B через релеи
2. B: телефон звонит → «Принять» → Answer уходит A через релеи
3. A: применяет Answer → ICE → CONNECTED

Запасной путь — ручная пересылка тех же строк через мессенджер.

## Не входит в scope

- Видео, чаты, файлы
- Собственные серверы разработчика
- Регистрация / номер телефона
